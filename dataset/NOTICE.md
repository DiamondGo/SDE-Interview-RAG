# Dataset notice

This directory holds interview questions, answers and interview-experience posts collected from public sources
(`raw/`). The database built from them (cleaned text, tags, search index, embeddings) is attached to the GitHub
release named in `MANIFEST.json`; `sde-rag import-data` downloads and verifies it. Both are published so that the
RAG system can be used without crawling everything again.

**The content belongs to its authors.** Every document keeps its source URL (`documents.url`), and every
question links to the documents it was found in (`question_mentions`). Licenses differ by source: question
repositories on GitHub carry their own licenses (some, for example, forbid commercial use or derivative works),
and articles and comments on dev.to and Hacker News belong to their writers. Check the original source before
reusing anything beyond personal interview preparation.

Not included: content from sources configured with `publish = false` (sites that need a login), and local
usage data (questions asked, feedback, alerts, run logs).

To have content removed, open an issue in this repository with the source URL.

Generated by `sde-rag publish-data`; see `MANIFEST.json` for counts and the embedding model.
