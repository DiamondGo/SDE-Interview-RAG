## 里程碑 1：骨架与最小闭环 —— 已完成，待验收

已交付：

- SQLite 存储和带版本号的迁移；文档保存原始下载和清洗后的正文；题目、标签、切块、FTS5 索引和向量全部持久化；
  向量快照带启动时一致性检查（只补新增部分；丢失时从数据库重建；从不重新计算向量）。
- 可配置的 agent：后端（OpenAI 兼容接口、CLI agent）和带备用链的角色，分层配置和环境变量覆盖，能力校验，
  `sde-rag agents show`、`sde-rag doctor`。
- 模型调用的卡死侦测：流式输出的首个 token 超时和间隔超时，结构化调用的硬性超时，输出重复循环检测，卡死后的健康探测和熔断。
- 身份与权限接口（默认：单用户、全部可见），检索链路全程经过它，并用限制性的策略做了测试。
- 连接器：GitHub 题库仓库（41 个）、Hacker News（Algolia API）、dev.to（公开 API），支持增量列表、“已见过”记录、
  条件请求、内容哈希和跨来源链接识别。
- Markdown 规则问答抽取（标题题目、编号列表里的标题、`<details>` 折叠块、题目列表），基于可配置分类体系的规则打标签和 LLM 打标签，
  完全相同的题目合并，并计算出现次数和热度。
- 混合检索（BM25 + 向量，RRF 融合）；查询图支持列出某方向的常见题和带引用的回答，校验引用，模型失败时给出降级回答。
- 抓取图：运行标识、数据库锁（持有者进程不存在时可接管）、心跳、断点续跑。
- 最小的评测图（检索自检）、带 `/health` 的 Gradio 网页界面、命令行。
- 公开数据集导出（`sde-rag publish-data`，Git LFS），不含本机使用数据。
- 测试：不需要网络的单元测试；在 `langgraph dev` 里运行查询图的集成测试。

第一次真实抓取（2026-10-31）：486 篇文档（GitHub 文件 314 个、dev.to 文章 150 篇、Hacker News 讨论 23 个），
6,535 道不同的题，7,585 个切块，用 `intfloat/multilingual-e5-large` 计算向量。

已知限制（计划在后续里程碑解决）：

- 只有规范化后文本完全相同的题才会合并（近似重复：里程碑 2）。
- 面经帖子以正文切块的形式入库；只有写成标题的题目会被抽出来（LLM 抽题：里程碑 2）。
- LLM 打标签每次运行处理 600 道题，其余的先保留规则标签，按顺序轮到。
- 评测图目前只检查索引能否用题目原文找回这道题（真正的评测集：里程碑 3）。
